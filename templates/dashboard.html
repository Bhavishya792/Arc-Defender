Developer Integration Guide

Connect your external APIs, web servers, or microservices to ARC Defender for real-time attack detection and ML anomaly scoring.

Ingest API: Ready & Listening
⚡
Mode 1: Remote HTTP Telemetry Ingest

Any external application (Python, Go, Java, Rust, Ruby, PHP) can stream HTTP telemetry events to ARC Defender via simple JSON POST requests.

POST /arc/api/v1/ingest
📦
Mode 2: Drop-in Node.js / Express Middleware

If your app runs in Node.js, drop the ArcDefenderClient middleware directly into your Express or Connect router pipeline.

app.use(arcClient.middleware());
